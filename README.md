# ❤️ Cardiac Disease Diagnosis System

A Machine Learning-based web application that predicts the likelihood of heart disease using patient health parameters. The system utilizes a trained machine learning model to analyze medical data and provide accurate predictions through an interactive web interface. Built with Python, Flask, HTML, CSS, JavaScript, and SQLite, the application demonstrates the integration of machine learning and web development for healthcare applications.

---

## 🚀 Project Overview

The Cardiac Disease Diagnosis System is designed to assist in the early prediction of heart disease by analyzing patient health information. Users can enter medical parameters through a web interface, and the trained machine learning model predicts whether a patient is likely to have heart disease.

This project demonstrates the implementation of:

- Machine Learning for Disease Prediction
- Data Preprocessing
- Model Training and Evaluation
- Flask Web Development
- Database Integration
- Interactive User Interface

## ⚙️ How It Works

1. Launch the application.
2. Open the web interface.
3. Enter patient health information.
4. The input data is preprocessed using the saved scaler.
5. The trained machine learning model analyzes the data.
6. The model predicts the likelihood of heart disease.
7. The prediction result is displayed instantly to the user.

---

## 📊 Input Parameters

The prediction model analyzes several health parameters, including:

- Age
- Gender
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol Level
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Slope of ST Segment
- Number of Major Vessels
- Thalassemia

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/foxylikith6-eng/cardiac-disease-diagnosis-system.git
```

### Navigate to the Project

```bash
cd cardiac-disease-diagnosis-system
```

### Install Required Libraries

```bash
pip install -r requirement.txt
```

Or install manually:

```bash
pip install flask pandas numpy scikit-learn joblib
```

---

## ▶️ Running the Project

Start the Flask application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

Enter the patient's health details and click **Predict** to view the diagnosis result.
