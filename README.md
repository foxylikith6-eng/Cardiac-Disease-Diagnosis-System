# Cardiac-Disease-Diagnosis-System
A machine learning-based web application that predicts the risk of heart disease using patient health parameters, built with Python, Flask, HTML, CSS, JavaScript, and SQLite.

Cardiac Disease Diagnosis System

The Cardiac Disease Diagnosis System is a machine learning-powered web application designed to predict the likelihood of heart disease based on patient health data. The application provides a simple and user-friendly interface where users can enter medical parameters and receive instant prediction results.

Features
- Heart disease prediction using Machine Learning
- User-friendly web interface
- Real-time prediction
- Secure patient data storage with SQLite
- Responsive design

Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- Scikit-learn
- Pandas
- NumPy

Project Structure
- `app.py` – Flask application
- `train_model.py` – Model training script
- `heart_model.pkl` – Trained ML model
- `templates/` – HTML templates
- `static/` – CSS, JavaScript, and images
- `database/` – Database files
